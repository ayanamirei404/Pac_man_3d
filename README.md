# 追逐游戏 (Chase Game)

一款基于 Godot 4.6 的 3D 迷宫追逐游戏。玩家在随机生成的迷宫中探索，同时躲避鬼魂的追捕。

![游戏演示](演示照片/屏幕录制%202026-06-04%20192312.gif)

## 玩法

- 在随机生成的迷宫中探索
- 使用手电筒照亮黑暗区域（按 **F** 开关）
- 按住 **Shift** 冲刺，但注意体力消耗
- 躲避鬼魂的追捕——被抓住则游戏结束
- 按 **N** 切换视角

## 操作说明

| 按键 | 功能 |
|------|------|
| W/A/S/D | 移动 |
| Space | 跳跃 |
| Shift | 冲刺 |
| F | 开关手电筒 |
| N | 切换视角 |
| ESC | 暂停菜单 |

## 游戏机制

- **随机迷宫**：每局游戏使用深度优先算法自动生成不同的迷宫，并随机打通额外通路
- **鬼魂 AI**：鬼魂具有三种状态——游荡（Wander）、追踪（Chase）、搜索（Search）。玩家进入鬼魂视野范围后会被追踪，丢失视野后鬼魂会在最后已知位置搜索
- **体力系统**：冲刺消耗体力，停止冲刺后自动恢复。体力耗尽后需回复到一定值才能再次冲刺
- **电量系统**：手电筒会持续消耗电量，关闭时缓慢恢复。电量耗尽后自动熄灯
- **移动端支持**：内置虚拟摇杆，支持手机触屏操作

## 技术栈

- **引擎**：Godot 4.6 (Mobile 渲染模式)
- **物理引擎**：Jolt Physics
- **渲染**：Direct3D 12（Windows）
